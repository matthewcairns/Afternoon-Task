# Afternoon user guide — getting client information into Afternoon

> Platform guidance supplied for the prototype. Siesta uses it to walk a first-time adviser
> through adding client data. The upload steps in the Siesta panel follow it exactly.

## 1. Upload documents and extract the data (usually quickest)

- Go to the client's Documents area and click **Upload from your computer**, or **Upload from SharePoint** if your files already live there (you connect your Microsoft account once, then browse and pick files).
- You can upload up to 5 files at a time — PDFs, Word documents, text files, images, spreadsheets and even audio/video.
- Before uploading, pick the right data upload model so the file is read correctly:
  - **Fact Find** — for your existing fact find documents
  - **Core** — the standard option for general documents like provider statements
  - **DARSCO** — for documents in DARSCO format
  - **IO Fund Valuation** — for fund valuation data
- Each file shows a status — **Extracting** (the platform is reading it with AI) then **Ready**. When it's ready, click **Process data**.
- You'll see everything it found, grouped into **new information**, **updates** and **conflicts**. Every field shows a citation — a link back to the exact text in the document it came from, so you can check it.
- If you trust the documents, use the global buttons **Add everything as new** or **Update all information** at once — that's the real time-saver. Otherwise handle items one by one (add, update or discard).
- Click **Finalise review** and it all lands on the client profile.

## 2. Connected valuation feeds (hands-off, ongoing)

- Pension and investment values can flow in automatically from provider feeds — ORIGO (the industry-standard feed) or FINIO.
- Data matches to clients by provider reference number and keeps values up to date in the background, with no uploading needed.
- If you're a system administrator, the **Company Data** page shows which providers are connected and when they last updated.

## 3. Manual entry

- Use the **Create** button on the client profile for anything missing — useful for gaps after a bulk upload.

## Practical tip

Batch-upload the fact find plus the key statements (5 files per batch), use **Add everything as new** / **Update all** when you trust the source documents, then top up any gaps manually. The documents stay in the client's Documents area afterwards too, so you keep the originals.
